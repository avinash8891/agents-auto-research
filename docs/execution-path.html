Controller Loop (Layer 1)

def _run_controller_loop(self):
while True:
execute_once() # one state-machine tick
 
if state in ('finished', 'interrupted', 'halted'):
return 0 # terminal — stop looping
if state == 'blocked' and blocker == 'research_required':
continue # research loop — go again
if state == 'blocked' (other):
return 1 # terminal blocker
 
def execute_once(self):
_ensure_job_metadata() # validate/init job context
_resolve_next_action() # → autoresearch_orchestration
if state == 'blocked' and research_required:
_run_research() # → autoresearch_research
if research ok: state = 'running'
if state == 'running':
_run_experiment() # → autoresearch_experiment

State Machine

running → next=run_baseline → running → run_experiment (baseline)
↓ baseline done
blocked next=research (research_required blocker)
↓ running research success → generated_config ready
↓ halted needs_code → compiler_builder runs
building → builder success → running
building → builder failure → halted (manual_review blocker)
↓ finished should_stop=True from conductor
↓ interrupted research failure / max retries
running → run_experiment (thesis N) → reconcile → loop
Key invariant: The state file (autoresearch.next.json) is the single source of truth. The controller reads it at each tick — it can be safely killed and resumed at any boundary between execute_once() calls.

Layer Detail — Functions

VPS Runner Entry
vps_runner.py
  • main()CLI entry. Loads .env, parses args, validates SSH config.
  • _activity_probe()Checks if another run is already active on VPS.
  • _git_prepare()Clone/fetch/checkout specified git ref on remote.
  • _upload_env()SFTP uploads .env.autoresearch + Codex auth bundle.
  • _invoke_remote()Runs controller with --prepare-launch-state-only then --run-current-state, streams stdout.
Controller State Machine
autoresearch_controller.py
  • main()Instantiates controller, normalizes launch state, starts loop.
  • _run_controller_loop()While-loop calling execute_once() until terminal state.
  • execute_once()One tick: ensure job → resolve action → research or experiment.
  • _ensure_job_metadata()Validates and initializes job context in state file.
  • reconcile_state()Recomputes state from all experiment results after each run.
Orchestration Next Action
autoresearch_orchestration.py
  • resolve_next_action()Waterfall: baseline rerun → resume halted → build → reconcile.
  • try_resume_halted_thesis()Materializes halted thesis runtime config and transitions to running.
  • build_missing_primitives_for_state()Marks state as building, invokes compiler_builder subprocess.
  • _activate_builder_config()On build success, sets up experiment with generated config.
  • _mark_builder_manual_review()On build failure, halts with manual_review blocker.
Planning What to Run
autoresearch_planning.py
  • plan_next_action()Top-level planner: forced baseline → no results → research waterfall.
  • select_research_next_action()Baseline branch → check termination → return blocked_for_research.
  • should_terminate()Checks latest research artifact for a should_stop signal.
  • check_baseline_rerun()Forces baseline rerun when strategy code changes detected.
Research Conductor Round
autoresearch_research.py
  • run_research()Increments research_round, invokes conductor, routes on result status.
  • _invoke_conductor_round()Calls execute_research_sdk(), accumulates token usage.
  • execute_research_sdk()Resolve inputs → validation retry loop → call conductor → dispatch result.
  • _try_one_validation_attempt()Stage1 validate → compile → stage2 validate → dispatch contract.
  • _handle_needs_code()Routes generated_config_needs_build → build_missing_primitives.
  • _handle_success()Sets state=running, next=run_experiment with validated config.
Experiment Backtest Run
autoresearch_experiment.py
  • run_experiment()Full backtest lifecycle: setup → validate → run → parse → evaluate → log.
  • _setup_run()Compute output dir, copy config into place.
  • _validate_backtest_request()Check config path, thesis id, round/job context before running.
  • controller.run_command()Subprocess backtest with 600s timeout, streams output.
  • controller.evaluate_metric()Compare metric vs baseline; if contract exists, run experiment_evaluator.
  • _finalize_experiment()Reconcile state, send Discord notification, emit trace event.
Research Conductor OpenAI SDK
research_conductor.py
  • run_research_conductor_sync()Sync wrapper around async conductor loop.
  • run_research_conductor()Build prompts → init agent with tools → run max 50 turns → parse JSON result.
  • analyze_trades()Tool: calls analyst subagent on trade data.
  • web_search()Tool: calls web-researcher subagent.
  • save_finding() / search_findings()Tool: persist/query MemPalace research memory.
  • list_experiment_results()Tool: query BacktestRunDB for past results (hard gate L7).
Compiler Pipeline Thesis → Config
compiler_pipeline.py
  • compile_research_thesis()Facade → compiler_research. Converts validated thesis dict to config.
  • build_missing_primitives()Subprocess → compiler_builder. Generates missing strategy code.
  • operationalize_thesis()→ compiler_operationalize. Turns compiled thesis into runnable config.
  • validate_orb_runtime_config()Strategy-specific config validation before backtest.

Key State Variables (autoresearch.next.json)

{
  "state":                     // running | blocked | halted | finished | interrupted | building
  "job":                       // current job ID
  "research_round":            // latest completed research round
  "research_round_in_progress": // round currently executing
  "current_best":              // { config, metric, timestamp } — best result so far
  "blockers":                  // list of { kind, detail } objects
  "next_action":               // { type, config, reason } — what to do next
  "halted_thesis_id":          // thesis awaiting code change or builder
  "halted_reason":             // requires_code_change | manual_review | ...
  "manual_review_theses":      // theses requiring operator action
  "builder_failed_theses":     // theses that failed the builder
  "job_usage":                 // { input_tokens, output_tokens, cost_usd }
  "heartbeat":                 // latest run status for external monitoring
}
