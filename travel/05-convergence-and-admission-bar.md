# 05 — Convergence & the Admission Bar

## The problem
"Loop until no new information" is, taken literally, infinite — someone always sells one obscure single-operator tour. Chasing literal zero pads the map with thin themes, which violates the depth-over-breadth and "don't pad" rules. So convergence needs a **quality bar**, not a zero-count.

## The admission bar (for a new THEME)
Admit a new theme only if ALL hold:
1. **≥ 2 credentialed, dated current-season (2026–27) expert-led products** — a named scholar/guide, not a figurehead; a real departure, not "ongoing."
2. **Non-overlapping** — not a sub-fold of an existing theme.
3. **First-trip-representative** — iconic and deep for the region, not hyper-niche.

Items that fail the bar become **sub-tags** under an existing theme (e.g. Cremona violins → under opera; Molise Samnite → thin-note), or are **folded/demoted**.

## How to COUNT toward the "≥ 2" (the arithmetic the run actually used)
- A product counts as **one (1.0)** only if it has BOTH a **named credentialed guide** AND a **confirmed current-season (2026–27) dated departure**, simultaneously.
- A product with the right structure but an **UNVERIFIED date or unnamed guide** counts as a **half (0.5)**.
- **"1.5 products" fails the bar** → record as a **THIN-NOTE**, not a theme, with a **re-test trigger**: re-evaluate if the operator later publishes a dated/named departure. (Molise Samnite and Cremona violins both failed here.)
- **Annual-catalogue exception**: an operator that demonstrably runs the trip *every year* but hasn't yet published the specific 2026–27 date counts as a **full product for THEME admission** (the theme clearly exists), but the row stays **UNVERIFIED for RANKING** until a dated departure is confirmed (`07`). Note the basis explicitly ("annual catalogue, date pending"). This resolves the apparent contradiction between "dated current-season" and admitting houses like Intermèdes/Clio/Arts et Vie.

## Inclusion / exclusion definitions (without these the bar is unusable)
- **Qualifying product** = a sold leisure tour. NOT a university course / master-class / lecture-residency / retreat / maker-workshop / day-activity / pilgrimage-without-study-content.
- **Qualifying operator** = a tour operator, NOT an aggregator/marketplace that resells other operators' trips (count the underlying operator, not the platform). Collapse absorbed sub-brands into the parent operator (e.g. Dr. Tigges → Gebeco) to avoid double-counting.
- **Qualifying expert** = a NAMED, credentialed scholar/specialist whose expertise fits the theme. NOT a title-only listing ("a Professor of X, name not published"), NOT a generic licensed city guide, NOT an artisan/trifolao unless the theme is the craft itself.

## Promotion vs sub-tag (cross-ref `04`)
Bare non-overlap is not enough to promote a sub-tag to a theme. It must also have a **standalone multi-day spine** and a **distinct buyer + supplier base**. See the promotion tests in `04-discovery-loop.md`.

## Two-level convergence
A country is DONE only when BOTH hold:
- **THEME convergence**: a fresh adversarial completeness-critic admits **0** themes clearing the bar.
- **OPERATOR convergence (per theme)**: each of the 5 axes returns dry for that theme (no new credentialed operator).

Track per-axis dry/not-dry in the corpus so convergence is **auditable, not asserted**.

## The false-convergence trap (mandatory check)
Theme convergence inside one axis is NOT global convergence. Before declaring done, confirm the LANGUAGE and AUTHORITY-INDEX axes have each been run and are dry. The Italy run declared convergence at round 4 and was wrong — round 5 (those two axes) added 26 operators. Always run all five axes to dry.

## Efficiency
Fold **operator-saturation into the ranking phase**: when you rank a theme, run the 5-axis check scoped to that theme. Discovery and ranking merge — no giant separate final sweep.

## Anti-patterns
- Declaring convergence from a single axis (English-only / operator-keyword) — the false-convergence trap.
- Counting an unnamed-guide or undated product as a full product toward the ≥2 bar.
- Padding a theme that fails the bar instead of recording a THIN-NOTE.
- Asserting "converged" without the auditable per-axis dry tracker.

## Output
A convergence tracker in the final theme map: per round, themes added/folded; per axis, dry status. Plus an explicit two-level "CONVERGED" statement citing the critic's empty result AND the language+authority axis-proof.
