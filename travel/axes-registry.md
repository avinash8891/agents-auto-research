# Global Axis Registry

The shared, evolving list of discovery axes. **Seeds every new country.** Append-only for promotions; never silently drop an axis. Per-country deviations live in `travel/<country>/axes.md` (see `03`, `06`).

Axis = an independent dimension where failing to search it causes systematic (not random) misses.
Promotion bar = provably surfaces tours no existing axis finds (cite the tours).

## BASELINE AXES (active for all countries)
1. **Channel** — provider type (8 sub-types A–H; see `03`).
2. **Lens** — experience/subject type (history, art, food, wildlife, …).
3. **Region** — every first-level admin region as a checklist.
4. **Language** — native + study-travel source languages (DE/FR/IT/…). *Proven: +17 operators on Italy.*
5. **Authority-index** — directories that list quality operators (awards, AITO/Virtuoso, university-alumni & museum travel partners, UNESCO). *Proven: +9 operators on Italy.*

## UPDATE PROTOCOL
1. New country inherits BASELINE + WATCHLIST.
2. Country's discovery + axis-completeness critic (`04`) tests candidates; results append to `travel/<country>/axes.md`.
3. A candidate that passes the promotion bar in a country → move it here (CANDIDATE→BASELINE) with a PROMOTION LOG entry citing the tours it uniquely caught.
4. Never remove a baseline axis; if one stops paying off in a country, note it inactive in that country's ledger, not here.
